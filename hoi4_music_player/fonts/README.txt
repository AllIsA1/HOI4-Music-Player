These are IBM Plex Sans Condensed (Regular, Medium, SemiBold) and IBM Plex Mono
(Regular) from https://github.com/IBM/plex ("complete" builds, with Cyrillic),
licensed under the SIL Open Font License 1.1 - see OFL.txt.

Modification: only the font naming was changed - each weight is its own
family ("HMP Sans", "HMP Sans Medium", "HMP Sans SemiBold", "HMP Mono") so Tk
can address every weight by family name and never mixes them up with a
system-installed Plex. "Plex" is a Reserved Font Name, so the renamed
families don't use it.
